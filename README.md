# ACCA4025 E-Portfolio

University E-Portfolio built with React + Vite for ACCA4025 – Learning in the Digital Era.

## Overview

This e-portfolio showcases the development of academic, digital, and professional skills through structured tasks and reflections. It includes:

- **Home**: Introduction and portfolio overview
- **Task 1**: Academic Skills Development
- **Task 2**: Digital Skills and Competencies
- **Task 3**: Professional Skills Enhancement
- **Task 4**: Reflective Practice and Synthesis
- **References**: IEEE-formatted citations and additional resources

## Features

- Responsive layout for all devices
- Accessible navigation menu
- Structured sections with summaries and reflections
- IEEE citation format for references
- British English formatting throughout
- Clean, professional design

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/valvdov/ePortfolio.git
cd ePortfolio
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

- React 19
